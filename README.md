# 504 word bot

This bot has 42 lessons and 504 words, which you can read and review through a story for each lesson. You can also add, remove, and update notes for each lesson, and set reminders to notify you to open your Leitner box and review them.

### Installation

Install the required libraries: telegraf, cron, moment, mongodb, and dotenv.
Add an .env file and set the following variables:
TELEGRAM_TOKEN_API
MONGODB_DATABASE
LESSON_PATH
WORD_PATH
Before starting the project, run npm run import to configure the bot.
Running the Bot

### Run

For development mode, run npm run dev.
For production mode, run npm run start.
